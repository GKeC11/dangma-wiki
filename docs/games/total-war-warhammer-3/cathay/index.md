# 震旦

震旦擅长以稳定前线保护远程与炮兵，通过阴阳宁和放大整支军队的效率。它的强项不是某个单位独自取胜，而是阵型中的不同兵种相互支持。

## 震旦作战核心

1. 阳系近战与阴系远程相互靠近，维持宁和。
2. 前排的任务是保持阵线，让远程火力持续工作。
3. 火枪和鹤铳需要无遮挡射界；弩手更容易部署。
4. 巨炮处理大型和重甲，火雨火箭炮处理密集步兵。
5. 快速单位负责侧翼、追击和保护后排，不要陷入无意义的正面混战。
