# 长垣关隘建设

长垣西段的蛇门关等城市属于**长垣关隘**，不按普通经济城建设。关隘只有少量建筑槽，主要职责是强化守城能力，并让防守部队以较低成本长期驻扎。

## 默认建造顺序

1. 等待人口盈余期间，先建造**降低本地区军队维持费、增加视野**的瞭望塔或要塞建筑链。
2. 人口盈余足够后，立即升级关隘主城序列，优先解锁槽位并强化城防驻军。
3. 第二个额外槽建造**水站—伙房—宴会厅**建筑链，获得全局发展和本地区补员。
4. 最后一个槽建造**木料—军械库**建筑链，提高守城战的防御补给和弹药。

默认的最终组合为：

> 关隘主城 + 维持费建筑 + 水站补员建筑 + 军械防御补给建筑

## 各建筑链的用途

| 建筑链 | 主要作用 | 推荐度 |
|---|---|---:|
| 瞭望塔—指挥塔 | 降低本地区驻军部队维持费、扩大视野 | 必建 |
| 水站—大雅间 | 提供发展和当地补员 | 推荐 |
| 木料堆—军械库 | 增加防御补给、被围期间补给及守城弹药 | 推荐 |
| 监牢—宝塔 | 减少混沌荒原损耗，降低本地招募费并提高新兵等级 | 招募基地可选 |

其中维持费建筑一级即可降低本地区军队维持费，满级效果可达到 `-65%`。因此，防守军必须站在关隘所在地区，才能充分利用该效果。

水站建筑链满级可提供所有省份发展 `+10` 和本地区军队补员 `+10%`。军械建筑链满级可提供防御补给 `+1500`、被围期间每回合防御补给 `+650`，并使本地区军队在守城战中的弹药 `+100%`。

## 招募基地变体

如果准备把某一座关隘作为北伐招募基地，可以使用：

> 关隘主城 + 维持费建筑 + 水站补员建筑 + 监牢招募建筑

这种方案舍弃额外防御补给，换取更低的本地招募费用、更高的新兵等级，以及进入混沌荒原作战时更低的损耗。满级监牢建筑链可提供本地区招募成本 `-65%`、所有单位招募等级 `+5`，并大幅减少混沌荒原损耗。

## 驻防建议

- 威胁较低时：普通领主加约 8 至 12 队玉勇、弩手与火炮。
- 长垣威胁升高时：补充至 14 至 20 队，并提前驻扎在关隘中。
- 关隘自带驻军会与领主军队共同参战，无需每座关隘长期维持昂贵的精锐满编。
- 如果经常手动守城，军械建筑的防御补给和弹药价值很高；如果主要主动出关作战，则监牢建筑更实用。
