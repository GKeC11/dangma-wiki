# 震旦兵表：特点与快速结论

> 适用范围：原版游戏 8.1，战役模式，不启用 SFO、Radious 或单位数值 Mod。

## 1. 快速结论

如果只想知道“什么最好用”，可以先记住下面这些结论：

| 需求 | 首选 | 次选或性价比选择 |
| --- | --- | --- |
| 最强正规抗线步兵 | 天廷龙卫（Celestial Dragon Guard） | 玉勇、玉勇（长戟） |
| 最强局部肉盾 | 俑士禁卫（Terracotta Sentinel） | 墨玉狮（Jet Lion） |
| 最便宜的拖延单位 | 农民长枪兵 | 玉勇 |
| 对步兵近战输出 | 虎人战士（双斧） | 翡翠狮、天狮 |
| 对大型近战输出 | 铁爪虎人战士、天廷龙卫 | 玉勇（长戟） |
| 最泛用远程步兵 | 天廷龙弩手 | 玉勇弩手 |
| 远程猎杀单体、重甲 | 鹤铳手 | 震旦巨炮 |
| 清理步兵群 | 火雨火箭炮 | 铁雹铳手、天舟 |
| 最强机动侧袭 | 天狮、巨月鸟、巨龙马骑兵 | 墨鸦人、虎人潜猎者 |
| 最强阵地辅助 | 战鼓 | 翡翠狮、墨玉狮、五行战争罗盘 |
| 最值得长期使用的中期核心 | 玉勇、玉勇弩手、震旦巨炮 | 玉勇（长戟）、鹤铳手 |

最稳妥的震旦战术不是让前排独立消灭敌人，而是让前排维持阵型和宁和，为弩手、火枪与炮兵争取输出时间。震旦的战斗效率来自整个阵型，而不是某一个“无敌单位”。

## 2. 评级方式

本文在每个能力维度内使用以下档位：

- **S：** 该维度的核心答案，能够直接围绕它构筑军队。
- **A：** 表现优秀，拥有清晰而可靠的战术价值。
- **B：** 合格或具有较高性价比，但存在明显限制。
- **C：** 专用或容易被替代，需要特定目标、阵型或操作。
- **D：** 不适合该维度；不表示单位在其他用途上也弱。

排名默认比较普通可重复招募单位。名望兵种单独说明，因为每种只能拥有一队，不能作为常规战线模板。

## 3. 震旦兵表的整体特点

### 3.1 核心优势

1. **阵地战完整。** 震旦拥有可靠的盾兵、长戟、弩手、火枪、狙击枪、巨炮和火箭炮，可以在一个阵型内解决几乎所有目标。
2. **宁和强化。** 大部分传统近战部队属于阳，远程部队属于阴；相反属性互相靠近后，会提高近战防御、士气或装填效率。离开阵型就等于主动放弃兵表强项。
3. **中级兵性价比高。** 玉勇和玉勇弩手并不华丽，却可以从中期一直使用到战役结束。
4. **反大型手段充足。** 长戟、天廷龙卫、铁爪虎人、鹤铳手和巨炮可以形成多层反大火力。
5. **辅助单位丰富。** 战鼓、双狮和战争罗盘能强化阵线、法术或抗魔能力。

### 3.2 核心弱点

1. **传统核心移动缓慢。** 玉勇和天廷龙卫速度低，转向、补洞和追击能力有限。
2. **害怕阵型被拆散。** 飞行单位、召唤物、潜行单位或高速骑兵进入后排后，宁和与射击线会一起失效。
3. **直射武器需要视线。** 铁雹铳手和鹤铳手不能稳定穿过己方步兵射击，必须预留缺口、侧翼或高地。
4. **不少强力单位是单体大目标。** 俑士禁卫和飞行怪兽容易遭到火枪、炮兵与反大型单位集火。
5. **虎人不是盾墙。** 虎人部队提供速度、伏击与冲击力，但不参与传统宁和体系，也普遍缺少盾牌；它们是进攻部队，不是玉勇的直接替代品。
