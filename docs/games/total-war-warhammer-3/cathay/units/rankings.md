# 震旦单位多维能力排名

> 排名综合基础数值、兵种机制、战役成本与操作要求，不是单挑榜。

## 4. 防御与抗线排名

### 4.1 正面战线综合评级

| 档位 | 单位 | 防御特点 | 主要限制 |
| --- | --- | --- | --- |
| S | 天廷龙卫 | 95 护甲、较高近战防御和士气；反大、破甲、反冲锋；站稳后能承受步兵、骑兵和怪兽压力 | 没有盾牌，仍怕高强度远程破甲；价格高 |
| S | 沙漠之龙（天廷龙卫名望兵） | 普通天廷龙卫的全面强化版，基础近防与士气明显更高 | 只能拥有一队 |
| S（局部） | 俑士禁卫 | 12620 生命、100 护甲、不可击溃；能堵缺口、缠住多队敌军，并鼓舞友军 | 只有一个模型，覆盖不了整条战线；近防仅属一般，怕反大与远程集火 |
| A | 玉勇（剑盾） | 盾牌、70 护甲、120 人；静止后进入防御姿态，宁和进一步增加近防和士气 | 缺少破甲与反大，杀伤较低 |
| A | 玉勇（长戟） | 比剑盾型更高近防；防御姿态、反大、破甲、反大型冲锋 | 没盾，承受弓弩和火枪时明显更差 |
| A | 铁爪虎人战士 | 8800 生命、75 士气、46 近防；反大、破甲、反大型冲锋，能在最危险处顶住大型敌人 | 仅 60 护甲、80 模型、无盾且不吃传统宁和；作为整线肉盾不够经济 |
| A（反魔法局部） | 墨玉狮 | 90 护甲、60 近防；给附近友军提供法术抗性，并能反射敌方弹药 | 仅 5808 生命的单体，无法覆盖战线，怕反大集火 |
| B | 农民长枪兵 | 160 人、总生命较高、价格极低；反大、全面反冲锋、可牺牲 | 15 护甲、低近防和低士气，遇到强力步兵或远程会快速损失 |
| B | 翡翠狮 | 90 护甲且具备阳宁和，能在局部堵住步兵并强化法术体系 | 近防明显低于墨玉狮，主要价值不是挨打 |
| B | 天狮 | 80 护甲、15% 抛射抗性、飞行、恐惧与恐怖；适合拦截突入后排的单位 | 更适合机动拦截，不适合长期陷入长戟阵 |
| C | 虎人战士（双斧） | 生命和士气尚可，可以依靠高杀伤减少受到的回击 | 30 护甲、无盾、近防一般；典型输出兵而非肉盾 |
| C | 虎人潜猎者 | 有物理抗性、潜行和机动性，能暂时接战 | 核心价值在远程骚扰和侧袭，正面站桩浪费能力 |
| D | 墨鸦人、农民骑兵、巨月鸟 | 可以应急拖住目标 | 生存、模型数或单位价值不适合作为固定前线 |

### 4.2 防守时如何选

- **敌人以步兵和弓弩为主：** 玉勇（剑盾）优先，盾牌能够减少接敌前损失。
- **敌人以骑兵、战车和怪兽为主：** 玉勇（长戟）或天廷龙卫优先，保持面向敌人并停止移动以获得反冲锋。
- **敌人有少量强力单体：** 用俑士禁卫接住，再由长戟、鹤铳手和巨炮集中处理。
- **敌人法术杀伤很强：** 墨玉狮放在核心战线附近，利用法术抗性光环；不要让它单独冲锋。
- **预算紧张：** 农民长枪兵负责牺牲，真正伤害交给弩手和炮兵。

单看“覆盖一整条战线的稳定性”，天廷龙卫第一；单看“单位成本与拖延时间”，玉勇通常优于把整线全部升级为天廷龙卫。

## 5. 近战进攻排名

### 5.1 近战步兵

| 档位 | 单位 | 最适合攻击的目标 | 说明 |
| --- | --- | --- | --- |
| S | 虎人战士（双斧） | 普通和精英步兵 | 42 近攻、54 武器威力、反步、快速冲锋；是震旦最明确的步兵切割者 |
| S | 铁爪虎人战士 | 重甲大型、骑兵、怪兽 | 高破甲、高反大和较好近防；既能迎击也能追杀大型目标 |
| A | 天廷龙卫 | 大型与重甲单位 | 破甲、反大并能反冲锋；杀伤稳定，但主要设计仍偏防守 |
| A | 虎人潜猎者 | 被投射武器削弱后的步兵与侧翼目标 | 潜行、先锋、边跑边射；先骚扰再接战才能发挥全部价值 |
| B | 玉勇（长戟） | 中低级骑兵和怪兽 | 价格合理的反大工具，但基础近攻较低，主动冲锋效率一般 |
| C | 玉勇（剑盾） | 低甲杂兵 | 能赢靠的是耐久，而非迅速杀敌 |
| C | 农民长枪兵 | 低级大型或已经被固定的目标 | 主要用于拖延，不应期待击杀效率 |

### 5.2 怪兽与单体进攻

| 档位 | 单位 | 进攻定位 | 说明 |
| --- | --- | --- | --- |
| S | 俑士禁卫 | 重甲单体、密集步兵、破阵 | 630 武器威力、高质量破甲；8.1 还获得削甲接触效果，能为后续火力创造条件 |
| A | 天狮 | 后排猎杀、士气打击、侧冲 | 飞行、恐怖与主动咆哮适合制造溃败；也是保护己方炮兵的快速拦截者 |
| A | 巨月鸟 | 侧后方冲击、清理聚集步兵、支援法师 | 更偏进攻和法术协同，不能当成高防御飞龙使用 |
| A | 翡翠狮 | 冲击步兵、提供法力恢复 | 55 近攻，附带两次范围吐息；适合法师较多的军队 |
| B | 墨玉狮 | 防守反击、保护后排 | 60 近防而只有 40 近攻，攻击能力次于翡翠狮 |
| B | 巨龙马骑兵 | 飞行侧冲和清除敌方远程 | 需要反复冲锋，持续混战效率不如专职怪兽 |
| C | 玉勇骑兵 | 侧冲普通步兵、追击溃军 | 依赖冲锋加成，陷入持续战斗后输出快速下降 |

## 6. 反大型能力排名

反大型应分为“接住目标”和“消灭目标”。最可靠的方法是让一层单位接战，再由另一层远程单位输出。

| 档位 | 单位 | 作用 |
| --- | --- | --- |
| S | 天廷龙卫 | 最完整的近战反大单位：高甲、高近防、破甲、反大和全面反冲锋 |
| S | 铁爪虎人战士 | 更偏主动猎杀大型目标，移动速度明显快于传统震旦步兵 |
| S | 鹤铳手 | 远距离削弱领主、怪兽、骑兵与重甲目标；需要无阻挡射界 |
| S | 震旦巨炮 | 极远距离打击大型、骑兵纵列和重甲单体；也是逼迫敌军进攻的核心 |
| A | 玉勇（长戟） | 中期最经济的反大前排，负责固定而非迅速击杀 |
| A | 俑士禁卫 | 没有传统反大标签，但高破甲、质量和削甲使其适合与大型目标互殴 |
| A | 天廷龙弩手 | 泛用破甲远程，可以稳定射击大型单位，不像鹤铳手那样依赖完美视线 |
| B | 墨玉狮、翡翠狮 | 能暂时卡住大型单位，但并非专职反大；应等待长戟或火力支援 |
| C | 农民长枪兵 | 便宜的第一道减速带，面对高级怪兽时只能争取时间 |

推荐的反大链条是：**玉勇长戟或天廷龙卫接战 → 鹤铳手与巨炮射击 → 铁爪虎人或俑士禁卫侧面加入。**

## 7. 远程输出排名

### 7.1 远程步兵

| 档位 | 单位 | 最强场景 | 主要限制 |
| --- | --- | --- | --- |
| S | 天廷龙弩手 | 对重甲、普通步兵和大型目标都稳定；自身也较耐打 | 昂贵、晚期兵种，仍需避免被真正的近战精英缠住 |
| S（性价比） | 玉勇弩手 | 中期通用火力，射程、弹药和持续输出稳定 | 对高甲目标效率逐渐下降 |
| A | 鹤铳手 | 超远程狙杀大型、领主、骑兵和重甲精英 | 直射视线严格，近战脆弱，地形和己方阵线都会挡枪 |
| A | 铁雹铳手 | 近距离爆发、重甲步兵和大型目标 | 射程短，需要缺口、侧翼或高地；遭冲锋时很脆弱 |
| A | 玉勇弩手（盾） | 与普通玉勇弩手相同的持续火力，并能更好承受敌方对射 | 更贵；如果敌方远程很弱，盾牌价值不高 |
| B | 虎人潜猎者 | 先锋骚扰、侧射、追击和近战收尾 | 8.1 后改为真正的远程散兵；持续正面射击不及正规弩手 |
| B | 农民弓手 | 对低甲大单位群和前期杂兵的廉价火力 | 穿甲差、士气和近战能力弱，后期需要逐步替换 |

### 7.2 炮兵与飞行火力

| 档位 | 单位 | 最强场景 | 说明 |
| --- | --- | --- | --- |
| S | 火雨火箭炮 | 密集步兵、驻军、缓慢重步兵 | 震旦最强清群炮兵；不适合射击贴着己方前排的小目标 |
| S | 震旦巨炮 | 单体、骑兵、战车、巨兽、城墙 | 泛用且招募较早，通常每支正规军都值得带一门 |
| A | 天舟 | 从空中持续轰击步兵，并携带炸弹 | 安全性取决于制空权；贵且怕飞行单位和远程集火 |
| B | 天灯 | 移动射击、破盾和宁和辅助 | 直接杀伤偏低，更多是辅助平台；后期容易被战鼓或其他火力替代 |

不要把鹤铳手和巨炮简单视为同一种单位：巨炮负责超远程开火、建筑和大体积目标；鹤铳手负责在交战期间继续精准射击单体与精英。

## 10. 各兵种综合战役价值

这一排名综合考虑强度、价格、招募时间、泛用性和操作要求。它不是单挑榜，也不意味着低档单位没有战术价值。

### 10.1 S 级：军队核心

- **玉勇：** 中期最稳定的盾墙，价格低，配合宁和、防御姿态和守门将后能长期使用。
- **玉勇弩手：** 震旦战役性价比最高的持续远程之一。
- **天廷龙弩手：** 后期泛用远程核心，对多数目标都有效。
- **震旦巨炮：** 招募早、射程远、用途多，能解决大型、骑兵、城墙和敌方炮兵。
- **火雨火箭炮：** 对步兵集群具有决定性杀伤。
- **俑士禁卫：** 后期局部锚点、怪兽杀手和破阵者；有治疗支援时价值更高。

### 10.2 A 级：优秀或关键专精

- 玉勇（长戟）
- 天廷龙卫
- 铁爪虎人战士
- 虎人战士（双斧）
- 虎人潜猎者
- 鹤铳手
- 铁雹铳手
- 玉勇弩手（盾）
- 翡翠狮、墨玉狮
- 天狮
- 战鼓
- 巨龙马骑兵

### 10.3 B 级：合格、专用或依赖编队

- 农民长枪兵、农民弓手
- 玉勇骑兵
- 巨月鸟
- 墨鸦人
- 五行战争罗盘
- 天舟
- 天灯

### 10.4 C 级：容易被替代

- **农民骑兵：** 追击、诱敌和占点有用，但正规战斗价值很低。
- **没有法师协同的翡翠狮：** 失去法力恢复与法术强度价值后，单靠肉搏不够划算。
- **没有射界的铁雹铳手和鹤铳手：** 数据再好，枪口被己方阵线挡住就等于没有输出。
- **失去制空权的天灯与天舟：** 被敌方飞行单位缠住后很难体现成本。
