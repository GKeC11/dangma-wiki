# 单位常见问题与资料来源

## 14. 常见问题

### 14.1 为什么天廷龙卫没有盾，仍然是最强正规抗线？

它具备高护甲、高近防、较高士气、破甲、反大和全面反冲锋，面对近战威胁非常全面。面对大量弓弩或火枪时，剑盾玉勇可能以更低成本承受更多前置伤害，因此不能无脑把所有玉勇替换掉。

### 14.2 玉勇剑盾和玉勇长戟该如何配比？

通常以剑盾为主、长戟为辅。中期可以采用四队剑盾加两队长戟：剑盾居中吸收步兵和远程伤害，长戟守两翼或专门接骑兵、战车和怪兽。

### 14.3 铁爪虎人是否比天廷龙卫更强？

铁爪拥有更高基础近防、生命和移动速度，主动猎杀大型目标更好；天廷龙卫拥有更高护甲、宁和、更多模型和全面反冲锋，更适合构成整条纪律严明的战线。二者是进攻型反大与防守型反大的区别。

### 14.4 为什么远程排名很高？

震旦前排的胜利条件不是自己杀光敌军，而是让后方武器持续工作。只要阵线不破，弩手、火枪和炮兵会把时间转化为伤害；因此“前排多撑半分钟”往往比“前排多杀几十人”更重要。

### 14.5 是否应该使用全怪兽前线？

可以娱乐，但不够稳定。单体怪兽覆盖宽度小，容易遭到反大和远程集火，也无法像步兵一样封锁多条通道。更可靠的做法是用传统步兵构成战线，把一至两尊俑士禁卫放在关键接触点。
