# 妙影流派

> 本页把妙影的开局发展、建筑规划、军队编制、技能加点和最终执行清单集中在一起。

## 开局发展方向

### 结论

妙影开局采用**经济与发展优先，保留最低限度军事建筑**的方案最稳定，大致可以理解为“七成经济、三成军事”。

原因：

- 早期真正限制扩张的通常是收入和补员，而不是兵种不够高级。
- 农民长枪兵、玉勇、农民弓手和玉勇弩手已经能组成有效的前期军队。
- 过早铺满军事建筑会占用建筑槽，还会拖慢主城升级。
- 妙影本人的战斗力和法术能力很强，不需要一开局就追求全高级兵。

### 什么时候增加军事投入

- 主城即将达到 3 级，可以解锁火炮或关键高级兵。
- 第二支军队准备独立作战。
- 北方压力增大，需要稳定补充守军。
- 收入已经能够同时维持两支军队，仍有余钱升级城市。

## 建筑顺序

建筑名称可能因阴阳版本、战役地图和汉化更新略有不同，因此以下以“功能”作为判断标准。

### 第 1 阶段：统一初始省份

#### 主城南皋

优先顺序：

1. **升级城镇序列**：有足够人口盈余和资金时优先升级主城。
2. **保留一个基础步兵招募链**：能招募农民长枪兵、玉勇等前排即可。
3. **发展建筑**：尽快积累人口盈余。
4. **经济建筑**：增加稳定的每回合收入。

如果开局已有能够提供核心兵种的军事建筑，不要为了“建筑整齐”立刻拆除；先完成统一战争，再根据长期规划调整。

#### 同省次要城镇

一般顺序：

1. 发展建筑。
2. 经济建筑。
3. 边境危险时再建城防或控制建筑。

同一省份已经有招募建筑时，次要城镇通常不需要再复制一套练兵营。

### 第 2 阶段：主城达到 3 级

1. 增建一条真正需要的高级军事链，优先考虑火炮或阵容中缺少的兵种。
2. 保持发展建筑，直到主城和次要城镇接近满级。
3. 其余空位继续补经济建筑。
4. 如果掌控力持续下降，才补掌控力建筑；不要在掌控力稳定时过早浪费槽位。

### 第 3 阶段：形成专门省份

将省份分工：

- **核心招募省**：集中军事建筑、招募等级和招募容量效果。
- **经济省**：发展完成后，尽量放经济建筑。
- **前线省**：城防、补员、控制和少量必要招募建筑。

这样比每座城市什么都建一点效率更高。

### 可直接照做的简化顺序

1. 初始主城：保留练兵营 → 建发展 → 建经济。
2. 第一个次要城镇：发展 → 经济。
3. 第二个次要城镇：经济 → 发展或城防。
4. 主城升 3 级：补火炮或所需高级军事链。
5. 省份接近满级：逐步拆除发展建筑，换经济、城防或高级军事建筑。

### 低成本过渡编制（20队）

| 类型 | 数量 |
|---|---:|
| 妙影 | 1 |
| 司天丞 | 1 |
| 农民长枪兵或玉勇前排 | 5 |
| 农民弓手或玉勇弩手 | 8 |
| 鹤铳手（近距离破甲火枪） | 2 |
| 农民骑手或玉勇枪骑兵 | 2 |
| 震旦巨炮 | 1 |
| **合计** | **20** |

这套阵容成本较低，足以完成早期统一和防守。

### 标准玉勇弩炮编制（20队）

| 类型 | 数量 |
|---|---:|
| 妙影 | 1 |
| 司天丞 | 1 |
| 持盾玉勇 | 3 |
| 长戟玉勇 | 2 |
| 玉勇弩手 | 7 |
| 鹤铳手 | 2 |
| 玉勇枪骑兵 | 2 |
| 震旦巨炮 | 2 |
| **合计** | **20** |

### 阵形与使用方法

- 阳系近战部队放前排，阴系远程部队放后排，保持和谐范围。
- 弩手不要全部排成一条过深的线，避免互相遮挡。
- 鹤铳手射线容易被己方前排挡住，放在两翼或前排预留的缺口中。
- 巨炮优先攻击敌方大型单位、精英步兵和远程火力。
- 骑兵主要负责清理敌方远程、追击溃军和保护侧翼，不要长时间陷入正面步兵战。

## 技能加点

妙影的加点根据操作方式分成两种：

- **经常手动战斗：法术优先。**
- **经常自动战斗：军队红线优先。**

### 推荐通用顺序

1. 蓝线第一个增加战役移动距离的技能点 1 点。
2. 点出“地血术”与生命系被动，提供稳定治疗。
3. 向“夜幕利爪”推进，获得清理步兵的强力范围法术。
4. 点“闪避”、魔法储备和奥术导管，提高施法效率。
5. 等级允许后，优先妙影的专属技能线。
6. 红线优先强化弩手、弹药、装填和前排防御。
7. 最后再补黄色个人近战线。

### 法术取舍

- **地血术**：低消耗治疗，前期性价比很高。
- **再生术**：治疗妙影、英雄或大型单体，适合中后期。
- **夜幕利爪**：对密集步兵的核心杀伤法术。
- **阴风暴与飞弹反射**：偏控制和针对远程，根据敌军阵容选用。

### 红线取舍

当前阵容以玉勇弩手和火炮为主时，优先点增加以下效果的红线节点：

- 远程伤害。
- 弹药量。
- 装填速度。
- 前排近战防御和领导力。

### 黄色个人线

妙影本身已经很强。除非你想让她长期以龙形态单独冲阵，否则黄色近战线不需要在前期抢点。

## 最终推荐清单

如果只想照着做：

1. 初始省份以发展和经济为主，只保留一套必要军事建筑。
2. 同一省份不要重复建设练兵营。
3. 主城优先升级，3级后补火炮建筑。
4. 妙影主军采用“5前排、7至8远程、2近距火枪、2骑兵、1至2火炮”。
5. 妙影手操时先点治疗、范围法术和奥术导管；自动战斗多则先强化军队红线。
6. 司天丞先沿天界法术线点到彗星、闪避与昊天导管。
7. 第一位普通副领主默认选昊天将军；军队缺法师时改选阴系龙裔修验官。
8. 发展完成后拆除发展建筑，换成经济、城防或高级军事建筑。
9. 长垣关隘优先建维持费建筑，随后选择补员和防御补给；作为北伐招募基地时再改建监牢建筑。
