# 司天丞

你截图中的角色是**司天丞**，不是领主。8.0以后司天丞技能树进行了调整，因此旧攻略中提到的某些技能可能已经改名、移动或删除。

## 截图中等级 2 的第一点

先沿当前可见的天界系法术线推进。若“和音汇集”可以升级，先投入这一点，再向后解锁“天空乱流”和“风爆术”。

## 推荐法术顺序

1. **和音汇集**：强化单个友军的近战能力，作为前置技能。
2. **天空乱流**：天界系被动，施法时削弱敌方飞行单位。
3. **风爆术**：前期清理低甲步兵，耗魔较低。
4. **夜风诅咒**：削弱敌方近战属性，适合帮前排扛线。
5. **尤瑞诺闪电箭**：对密集单位或固定目标造成伤害。
6. **闪避**：降低法术消耗并通向高级施法技能。
7. **卡莎朵拉彗星**：后期核心范围爆发，但需要预判落点。
8. **链式闪电**：敌军数量多时可用，稳定性不如彗星。
9. **昊天导管**：提高整体施法效率，解锁后优先。

## 12级以后

- **顺应天象**：增加魔法之风储备获取，解锁后优先考虑。
- **无匹司天术**：通用法术强化，普通弩炮军最适合。
- **观星结界**：军队中大量使用玉狮、墨狮或俑士禁卫时选择。
- **天契羁绊**：军队中大量使用太月禽、昊天狮等单位时选择。

这些专精技能要根据实际编制决定，不需要一看到就全部抢点。

## 战役地图技能

如果司天丞长期随军作战：

- 优先法术、施法被动和随军增益。
- “窃取科技”“击伤人员”“阻碍敌军”“行家里手”等地图行动技能可以后点。

如果司天丞专门在地图上行动：

- 优先“行家里手”。
- 再强化你最常用的行动，例如“窃取科技”或“阻碍敌军”。
