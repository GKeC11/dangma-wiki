# 发展、经济与招募

> 适用版本：8.1 原版。

## 发展与招募成本

### 1. “发展”有什么用

“发展”就是其他派系常说的**增长（Growth）**，它决定一个省份获得人口盈余的速度。

作用流程：

1. 每回合结算该省份的发展值。
2. 累积到阈值后获得 1 点人口盈余。
3. 升级主城或次要城镇的城镇序列时，需要消耗人口盈余。
4. 城镇等级越高，所需人口盈余通常越多。

重要规则：

- 发展通常是**省份资源**，同一省份内的城镇共享，不是全势力通用。
- “发展 +70”不是立即让城市升级，而是加快每回合积累人口盈余。
- 前期发展非常重要，因为高等级主城能够解锁更高级建筑和兵种。
- 当该省所有城镇都达到最高等级后，发展基本失去作用，可以把发展建筑拆掉，换成经济、控制或防御建筑。

### 2. 建筑上的“招募成本 -2%”是全局效果吗

**通常不是全局效果。**

判断方法：

- 如果效果是全局的，提示一般会明确写“全派系”“所有军队”或类似说明。
- 建筑只写“招募成本 -2%”而没有全局说明时，通常只作用于该建筑所在省份中的招募。
- 它主要降低在该省进行本地招募时的费用；不要把它当作所有城市、所有军队永久降低 2%。

因此，截图中的“篝火地坑”主要是**发展建筑附带一点本地招募优惠**，核心价值仍然是“发展 +15”，而不是 2% 的招募折扣。

## 军事建筑是否需要重复建造

### 同一个省份内

**一般不需要重复建。**同一省份中的本地招募通常共享该省已解锁的兵种。重复练兵营不会让同一种兵突然变得更强，单纯为了再次解锁相同兵种通常浪费建筑槽。

### 不同省份之间

是否建造取决于距离和用途：

- 后方军队可以接受更贵、更慢的全局招募：不用重复建。
- 新前线距离核心招募省很远，需要快速补兵：可以再建一套。
- 建筑明确提供英雄容量、招募等级或本地招募容量：即使兵种已经解锁，重复建造仍可能有价值。

判断口诀：

> 同省不重复，远方前线再复制；先看附加效果，不只看解锁兵种。
