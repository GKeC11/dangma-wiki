# 迪卡拉领地与建筑管理

> 适用范围：原版游戏 8.1，迪卡拉的折磨者派系。本文中的省份组合是根据建筑效果与地图形势给出的实战模板，不是唯一正确配置。

![迪卡拉领地概览](/images/warhammer3/dechala-settlement-overview.png)

## 一句话结论

迪卡拉的聚落不应全部采用同一种建设方式。每个聚落先指定一种职责：

| 聚落类型 | 核心用途 | 最适合的位置 | 主要缺点 |
| --- | --- | --- | --- |
| **奴工营地** | 抽取奴工、发展、补员和前期收入 | 新占地区、安全后方小城 | 地区奴工人口会逐渐耗尽 |
| **折磨者城塞** | 招募、驻防、腐蚀和前线支援 | 边境、隘口、容易遭到反攻的小城 | 经济与奴工产出较低 |
| **欢愉宫殿** | 高级招募、长期收入、防御与全局强化 | 只能建在省会 | 所有建筑与升级消耗奴工，前期铺得太快会断掉循环 |

最稳定的四城省通用模板是：

> **省会建欢愉宫殿，关键隘口建折磨者城塞，其余两座安全小城建奴工营地。**

## 奴工营地：快速提取型经济区

奴工营地把地区人口持续转化为全局奴工，同时提供发展、补员和金钱。它适合新占地区和安全小城，但不能当作永久经济来源：地区奴工人口耗尽后，产能会明显衰退。

### 核心建筑方向

| 建筑方向 | 代表建筑与效果 | 什么时候优先 |
| --- | --- | --- |
| 主城链 | 奴工营地废墟 → 奴工围场 → 奴工巢穴 → 奴工大院 | 提供槽位与基础功能，按需要升级 |
| 奴工输送 | **The Toll**：一级每回合消耗 25 地区奴工人口，向全局池加入 5 奴工 | 急缺全局奴工、当地人口充足时 |
| 发展与补员 | **Field Treatment**：补员 +3%、全省发展 +30、地区奴工人口消耗速度 -5% | 最通用，主力经过或希望延长营地寿命时优先 |
| 收入 | 营地金钱收入链 | 安全后方、有足够剩余人口时 |
| 驻军 | **Forbidding Fastness** | 仅在暴露于敌军攻击的小城使用 |

### 建筑优先级

**新占领地区：**

> 主城升级 → 奴工输送 → Field Treatment → 收入 → 资源/港口

**主力补员地区：**

> Field Treatment → 奴工输送 → 收入

**暴露边境：**

> Field Treatment → 驻军 → 奴工输送

地区奴工人口已经接近耗尽时，不要继续升级高价抽取建筑。先看这个据点的战略位置，再决定保留或转换。

### 何时转换

- 后方且拥有资源、港口或地标：可以保留，停止追加昂贵投资。
- 位于边境、隘口或需要补兵：转换为折磨者城塞。
- 位于省会、该省已经安全且全局奴工储备充足：转换为欢愉宫殿。

正常转换会使聚落主城降低一级，7.1 补丁还专门修复了转换时偶尔不降级的问题。因此不要在三种类型之间频繁来回切换。

## 折磨者城塞：前线军事节点

城塞负责中级单位招募、守城和传播色孽腐蚀。它能提供掠夺者、地狱行者、怒妖等前中期兵种，并把边境小城变成补兵与拦截节点。

### 核心建筑方向

| 建筑 | 用途 |
| --- | --- |
| **Marauders’ Hold** | 凡人步兵与掠夺者方向 |
| **Hellstrider Pens** | 地狱行者与骑兵方向 |
| **Shrine of Decadence** | 恶魔及其他中级兵种方向 |
| **Sentinel Fields** | 防御、驻军、防御补给，并降低敌方英雄行动成功率 |
| **Warhost Supplies** | 强化当地驻军，并提高全派系战后掳掠、洗劫与劫掠占领收益 |

Sentinel Fields 还会提高本省奴工营地收入，因此“一个城塞保护同省多个营地”比每座营地各自浪费槽位造驻军更划算。

### 建筑优先级

**普通前线城塞：**

> 城防链 → 掠夺者步兵链 → 地狱行者链 → Warhost Supplies

**迪卡拉主力补兵点：**

> 掠夺者步兵链 → 地狱行者链 → 城防链

迪卡拉能专门强化掠夺者和地狱行者，早中期不必把所有招募链都造齐，只保留当前军队实际使用的两条。

**守城专用节点：**

> 城防链 → Warhost Supplies → 一条便宜基础招募链

**恶魔方向副军：**

> Shrine of Decadence → 城防链 → 骑兵或支援链

高级恶魔和专业单位应由欢愉宫殿集中招募，城塞无需承担所有兵种。

## 欢愉宫殿：长期核心城市

欢愉宫殿只能建在省会，所有建筑和升级消耗奴工而不是金钱。它不依赖会枯竭的地区奴工人口，是中后期稳定收入、高级招募和全局强化的核心。

### 主要建筑方向

- 宫殿收入、贸易与腐化度。
- 领主、英雄等级与英雄容量。
- 法师招募、魔法之风与法术抗性。
- 研究速度、腐蚀和全军经验。
- 高级凡人招募。
- 高级恶魔招募。
- 宫殿城防。
- 迪卡拉个人强化。

代表建筑包括：

| 建筑 | 作用 |
| --- | --- |
| **Halls of Strife & Succour** | 强化本省新招募单位的近战防御，并产生腐化度 |
| **Flenser’s Workshop** | 研究、腐蚀与部队经验 |
| **Pain Vaults** | 法师与魔法支援 |
| **Altar of Dissolution** | 高级恶魔招募 |
| **Private Chambers** | 迪卡拉个人强化，需要较高宫殿等级 |
| **Dizzying Battlements** | 城墙、防御补给、守城能力与邻省军队支援 |

### 第一座宫殿怎么建

> 收入/腐化度 → 当前主力需要的一条高级招募链 → 城防或研究 → 英雄建筑

第一座宫殿不要同时造齐所有兵营，只承担一种主力体系：

- 迪卡拉凡人大军：优先高级凡人兵营。
- 妖女、逐心者与高级恶魔：优先恶魔招募链。
- 边境宫殿：城防排在第二或第三槽。
- 安全后方宫殿：优先收入、研究和英雄容量。

### 多宫殿专业化

形成两到三座成熟宫殿后，让宫殿收入逐步接替开始衰退的奴工营地。不同宫殿不要复制同一套建筑：

- **凡人兵站宫殿**：混沌勇士、神选者、冠军和高级骑兵。
- **恶魔兵站宫殿**：妖女、逐心者、战车、巨兽与守密者。
- **经济研究宫殿**：收入、研究、英雄容量与全军经验。
- **边境堡垒宫殿**：城防、一条主力招募链、补员与魔法支援。

高级招募集中在一到两个交通方便的省会即可，其余宫殿专注长期收入和全局加成。

## 每省推荐组合

### 标准四城省

> 省会：欢愉宫殿
>
> 隘口或边境小城：折磨者城塞
>
> 其余两城：奴工营地

这是最稳的通用模板：宫殿负责长期收入和高级招募，城塞保护全省并强化营地，两个营地供应奴工。

### 安全后方省

> 省会：欢愉宫殿
>
> 其余小城：全部奴工营地

不建多余驻军，把槽位投入奴工、发展、收入、资源和港口。

### 新征服前线省

> 省会暂时建折磨者城塞
>
> 隘口建折磨者城塞
>
> 其余地区建奴工营地

先防止敌人夺回；局势稳定并积累足够奴工后，再把省会转换为欢愉宫殿。转换存在降一级代价，尽量一次决定。

### 战略缓冲省

> 省会：欢愉宫殿或城塞
>
> 两个容易受攻击的小城：折磨者城塞
>
> 最安全的小城：奴工营地

适用于双线接敌、敌军频繁渡河或穿越山口的地区。

## 截图中的震旦腹地怎么规划

截图显示约第 6 回合、376 奴工，全省掌控力为负。对库里什之门、隐秘堡、山区隘口、南驿这一组地区，推荐最终规划：

- **真正的省会**：欢愉宫殿。
- **山区隘口**：折磨者城塞。
- **隐秘堡**：奴工营地。
- **南驿**：奴工营地。

如果库里什之门是省会，就在完成征服后将它作为第一座欢愉宫殿；若省会图标实际在其他地区，则把宫殿规划移动到真正的省会。

当前操作顺序：

1. 先完成全省征服，避免在即将反复易手的城市投入太多。
2. 山区隘口保留为折磨者城塞，优先掠夺者或地狱行者招募链。
3. 隐秘堡和南驿建奴工营地，先造奴工输送与 Field Treatment。
4. 第一座宫殿只造收入/腐化度和一条核心兵营，不要一次耗光奴工。
5. 当前掌控力约 -11，先用戒律、驻军或腐蚀建筑稳定省份，再继续升级宫殿。

## 前中后期清单

### 前期

- 新占小城优先奴工营地，主要进攻方向设置一个折磨者城塞。
- 第一座安全省会尽早转换为欢愉宫殿，但只升级一条主力招募链。
- 保留奴工储备，不要为了填满建筑槽把奴工全部花完。

### 中期

- 建立第二、第三座宫殿，让稳定收入逐步接替衰退营地。
- 把人口耗尽且位于战略位置的营地转换为城塞。
- 高级招募集中在少数宫殿，其余宫殿发展收入、研究和英雄容量。
- 每个边境省至少设置一个城塞。

### 后期

- 后方宫殿转为经济、英雄与全局强化中心，前线宫殿补足城防和高级招募。
- 已枯竭的营地只保留资源、港口或地标价值；无战略价值时停止投资。
- 通过持续扩张建立新营地维持奴工输入，不要试图永久依赖旧营地。

## 常见错误

- 全部城镇都建奴工营地，导致中期同时枯竭、收入骤降。
- 全部小城都建城塞，导致没有足够奴工升级宫殿。
- 过早铺多个宫殿并同时升级，瞬间耗光奴工。
- 每座宫殿复制全部招募建筑，浪费槽位和资源。
- 在安全后方营地造驻军，而不是发展、奴工和收入。
- 营地人口一降低就立即转换，白白承担主城降级。
- 忽略山区隘口、渡口和边境城镇的城塞价值。
