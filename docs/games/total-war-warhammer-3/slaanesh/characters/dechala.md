# 『背弃者』迪卡拉

> 适用范围：原版游戏8.1，战役模式。机制说明以游戏界面和 Creative Assembly 官方介绍为依据。

迪卡拉的玩法可以概括为：

> **不断征服城镇 → 榨取奴工 → 建设欢愉宫殿 → 生产恶堕并解锁强化 → 发动下一轮征服。**

她不是传统的防守经营型领主。最佳节奏是快速夺取土地，暂停数回合调整城镇和军队，然后继续寻找新的奴工来源。

## 战役核心循环

1. 通过战斗、占领城镇和色孽机制获取奴工。
2. 把占领的城镇转换为三种专用类型之一。
3. 奴工营地把当地有限人口汇入全局奴工池。
4. 使用奴工建设欢愉宫殿、发动军队恩惠或执行其他派系行动。
5. 欢愉宫殿产生恶堕，用于购买折磨者贡品和长期升级。
6. 当旧奴工营地逐渐枯竭后，继续征服新的城镇。

战前诱惑和解放人类、精灵附庸仍然可用，但它们是通用色孽工具，不是迪卡拉最主要的经济引擎。

## 三种专用城镇

| 城镇类型 | 主要用途 | 推荐位置 | 注意事项 |
| --- | --- | --- | --- |
| **欢愉宫殿** | 核心经济、高级兵招募、区域防御、产生恶堕与全局强化 | 重要省会 | 只能建在省会且数量有限；建筑主要消耗奴工而非金钱 |
| **奴工营地** | 把当地人口转成全局奴工，同时提供发展、补员和收入 | 安全后方与新征服地区 | 当地奴工人口有限，耗尽后生产效率会明显下降 |
| **折磨者城塞** | 本地招募、前线防御和传播腐蚀 | 边境、要道和不稳定地区 | 可以补充低中阶军队，但高级与专门单位仍主要依靠欢愉宫殿 |

简单判断：**重要省会建欢愉宫殿，安全地区建奴工营地，边境要地建折磨者城塞。**

两三座成熟欢愉宫殿可以提供稳定收入，缓解后方奴工营地逐渐衰退造成的经济压力。

## 资源怎么花

### 奴工

主要用于：

- 建设和升级欢愉宫殿。
- 使用军队的色孽恩惠，换取数回合的临时强化。
- 执行部分色孽仪式、教团或派系行动。

前期应先保证第一座欢愉宫殿能够建设和升级，再考虑频繁开启临时恩惠。

### 恶堕

恶堕主要由欢愉宫殿建筑产生，用于购买折磨者贡品，包括：

- 战前使用的一次性单位强化。
- 领主和英雄使用的独特魔法物品。
- 与欢愉宫殿建筑链关联的永久全局升级。

一般优先购买能够强化经济、招募能力或迪卡拉本人的长期升级。一次性强化留给真正困难的战斗。

### 金钱

仍然负责普通单位招募和军队维持费。由于欢愉宫殿主要消耗奴工建设，迪卡拉通常可以把更多金钱投入军队扩张。

## 战斗风格

迪卡拉属于**高速刺杀、侧后夹击、连续转场**型领主。她不是固定在前线承受伤害的坦克。

### 标准战斗循环

```text
步兵固定敌军
→ 迪卡拉与高速单位集中一侧
→ 绕后攻击远程、法师或已接战单位
→ 制造侧后冲锋与局部包围
→ 击溃目标后立即脱离
→ 转向下一支敌军，形成连续溃败
```

### 迪卡拉本人的任务

优先攻击：

1. 炮兵和远程步兵。
2. 脆弱法师与落单英雄。
3. 已经被己方步兵固定的单位侧后方。
4. 正在动摇或溃逃的高价值目标。

尽量避开：

- 长枪、长戟和其他反大型单位。
- 强力近战决斗领主。
- 多队敌军形成的包围。
- 火枪、弩手和炮兵的集中射击。

她的优势是极高速度与出色的加减速能力。正确操作是频繁接敌和脱离，而不是站在一个目标旁边持续互砍。

## 军队搭配与阵型

迪卡拉的技能可以强化掠夺者步兵、骑兵、战车和地狱行者。前中期不必急于把整支军队换成昂贵恶魔。

推荐分工：

- **中央4—6队：** 奉献掠夺者、奉献者或持鞭混沌勇士，负责暂时固定敌军。
- **两翼4—6队：** 地狱行者、探索骑兵、战车、色孽兽或其他高速单位。
- **角色：** 迪卡拉负责后排刺杀；斯提卡尔进一步放大掠夺者部队。
- **预备队1—2队：** 拦截敌方骑兵，或在突破后加入追击。

不要平均分散所有高速单位。将大部分机动力集中在一侧，先打穿一个翼，再从侧后方卷向中央。

## 与妙影的区别

两人的战斗逻辑几乎相反：

| 对比 | 妙影 | 迪卡拉 |
| --- | --- | --- |
| 军队风格 | 防守型远程阵地战 | 进攻型高速近战 |
| 主要输出 | 弩手、火枪、炮兵和法术 | 侧后冲锋、快速近战和士气打击 |
| 前排任务 | 长时间稳定抗线 | 暂时黏住敌人 |
| 领主定位 | 法师、治疗者、龙形局部肉盾 | 高速刺客与侧袭者 |
| 开战节奏 | 让炮兵逼迫敌军进攻 | 主动分割、包围和追击敌军 |
| 操作要求 | 维持宁和、阵型和射界 | 频繁移动、冲锋、撤离和更换目标 |
| 容错率 | 较高 | 较低 |

一句话记忆：**妙影不要乱动，迪卡拉不要站桩。**

## 迪卡拉技能加点

> 适用：原版 8.1。迪卡拉前期不缺个人输出，最缺的是奴工循环、扩张节奏和被她强化过的掠夺者部队。

### 你当前这一级怎么点

截图中已经有 **赶路人**，这一级直接点 **极乐奴隶**。它比纯个人战斗属性更早改善迪卡拉的奴工循环。

### 通用扩张流顺序

1. **赶路人** → **极乐奴隶**。
2. **屈服或灭亡** → **洗劫者**；前期连战、占城和抢资源时收益最直接。
3. 进入红线，优先点你军中实际最多的 **掠夺者步兵、地狱行者、战车**；不要平均分配给暂时不用的恶魔兵。
4. 取得专属线的 **色孽之赞**，再点 **腐烂圣杯** 与 **罪孽之酬**。这三项会把迪卡拉麾下的掠夺者、骑兵、战车与地狱行者从过渡兵提升成主力。
5. 中期补 **闪击战**，敌军多支部队互相支援时才有价值。
6. 后期才补黄线：**柔软灵活**、**异界反射**、**致命冲锋**、**皮糙肉厚**。这时她才更适合稳定单切领主和后排。

### 两个取舍

- 你现在主要用掠夺者与地狱行者：先红线和专属线，收益远高于黄线的个人面板。
- 你想把迪卡拉当刺客手操：在拿到 **色孽之赞** 后，提前补 **柔软灵活 → 异界反射 → 致命冲锋**；但仍不建议在前期完全放弃蓝线资源。

前期暂缓 **弥散腐蚀** 和只针对特定敌人的黄线技能：它们不会像奴工、部队强化和闪击战那样立刻改变你的扩张效率。

## 科技树推荐加点

![迪卡拉色孽科技树](/images/warhammer3/dechala-tech-tree.png)

迪卡拉的科技不要平均分配，推荐遵循：

> **经济建设 → 主力部队减维护 → 腐蚀与补员 → 战斗强化 → 外交与特殊兵种。**

### 推荐研究路线

1. **感官之欲**
2. **支配控制气味**经济线
3. **肉欲苦痛体味**中的维护费与战后收益科技
4. **神圣加持香精**中的腐蚀、法术和军队能力科技
5. 掠夺者强化
6. 地狱行者强化
7. 全军伤亡补员
8. 恶魔、战车、守密者和外交专项科技

### 第一阶段：先完成经济线

进入**支配控制气味**后，查看各科技的当前版本效果，优先研究：

1. 全部建筑建造成本降低。
2. 城镇建造时间减少。
3. 发展增加。
4. 补齐前置并取得分支末端的综合经济收益。

迪卡拉需要连续占城，并把城镇转换成欢愉宫殿、奴工营地或折磨者城塞。越早取得建设与发展加成，覆盖的城镇和回合越多，累计收益越高。

### 第二阶段：降低军费并放大征服收益

**肉欲苦痛体味**推荐顺序：

1. **追求富裕**：适合经常劫掠占领城镇的常规扩张路线。
2. **富足辛劳**：适合洗劫后再占领，补充即时现金。
3. **肆意破坏**：适合焚毁城镇，但迪卡拉通常需要保留聚落建立专用城镇，所以排在后面。
4. **痛楚气息**：经常使用战前诱惑时提前，否则稍后再点。
5. 补齐其余前置，再考虑**胜利与酷刑**。

前三项同时服务于军费控制和战后经济，非常符合迪卡拉持续进攻的战役节奏。**胜利与酷刑**曾在7.0.3修复效果，具体收益应以当前版本悬浮说明为准，不要照搬更早版本的攻略。

### 第三阶段：腐蚀与战斗能力

**神圣加持香精**推荐顺序：

1. **黑暗亲王之息**：优先解决新占区域的色孽腐蚀问题。
2. 提供法术冷却或全军战斗能力的科技。
3. **肉体堕落、神圣极致**等外交科技最后研究。

迪卡拉开局位于震旦附近，周围缺少色孽、诺斯卡、野兽人等天然外交对象，因此外交加成通常不如腐蚀和战斗强化实用。如果新占省份秩序稳定、腐蚀增长也没有压力，可以把这一阶段推迟到主力兵种强化之后。

### 后续最高优先级

科技树继续展开后，看到以下效果应优先研究：

| 优先级 | 科技效果 | 原因 |
| --- | --- | --- |
| **S** | 掠夺者维护费降低、近战能力提高或获得接触效果 | 迪卡拉和斯提卡尔都适合强化掠夺者体系，覆盖部队多且成型早 |
| **S** | 地狱行者维护费降低、冲锋加成提高 | 强化主力侧袭与追击单位，直接匹配迪卡拉的高速包围打法 |
| **S** | 全军伤亡补员提高 | 缩短连续征服之间的休整时间 |
| **A** | 色孽、阴影法术冷却或军队能力 | 有对应法师和频繁手动战斗时价值较高 |
| **B** | 妖女、逐心者、战车等专项强化 | 只有主力大量使用对应单位时提前 |
| **C** | 守密者专项强化与远方势力外交 | 高级兵成型或制定明确外交路线后再研究 |

### 可以直接照抄的顺序

```text
感官之欲
→ 支配控制气味经济线全部完成
→ 追求富裕
→ 富足辛劳
→ 肆意破坏
→ 黑暗亲王之息
→ 掠夺者强化
→ 地狱行者强化
→ 全军补员
→ 其他战斗科技
→ 外交、战车、恶魔与守密者专项科技
```

如果主力提前转成妖女、逐心者或守密者，应把对应的维护费和属性科技插入掠夺者强化之后；否则不建议为了尚未招募的高级兵牺牲前期经济和补员速度。

## 前期执行清单

1. 尽快建立第一座欢愉宫殿并启动恶堕生产。
2. 安全小城优先转换为奴工营地。
3. 面向主要敌人的前线设置折磨者城塞。
4. 先用廉价前排填满阵线，把预算投入高速侧袭单位。
5. 保持主动进攻，避免奴工来源中断。
6. 永久贡品和全局升级优先于普通战斗中的随意消耗。
7. 手动战斗中集中打穿一翼，不要让全军正面平推。
