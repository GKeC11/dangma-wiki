# 『背弃者』迪卡拉

> 适用范围：原版游戏8.1，战役模式。机制说明以游戏界面和 Creative Assembly 官方介绍为依据。

迪卡拉的玩法可以概括为：

> **不断征服城镇 → 榨取奴工 → 建设欢愉宫殿 → 生产恶堕并解锁强化 → 发动下一轮征服。**

她不是传统的防守经营型领主。最佳节奏是快速夺取土地，暂停数回合调整城镇和军队，然后继续寻找新的奴工来源。

## 战役核心循环

1. 通过战斗、占领城镇和色孽机制获取奴工。
2. 把占领的城镇转换为三种专用类型之一。
3. 奴工营地把当地有限人口汇入全局奴工池。
4. 使用奴工建设欢愉宫殿、发动军队恩惠或执行其他派系行动。
5. 欢愉宫殿产生恶堕，用于购买折磨者贡品和长期升级。
6. 当旧奴工营地逐渐枯竭后，继续征服新的城镇。

战前诱惑和解放人类、精灵附庸仍然可用，但它们是通用色孽工具，不是迪卡拉最主要的经济引擎。

## 三种专用城镇

| 城镇类型 | 主要用途 | 推荐位置 | 注意事项 |
| --- | --- | --- | --- |
| **欢愉宫殿** | 核心经济、高级兵招募、区域防御、产生恶堕与全局强化 | 重要省会 | 只能建在省会且数量有限；建筑主要消耗奴工而非金钱 |
| **奴工营地** | 把当地人口转成全局奴工，同时提供发展、补员和收入 | 安全后方与新征服地区 | 当地奴工人口有限，耗尽后生产效率会明显下降 |
| **折磨者城塞** | 本地招募、前线防御和传播腐蚀 | 边境、要道和不稳定地区 | 可以补充低中阶军队，但高级与专门单位仍主要依靠欢愉宫殿 |

简单判断：**重要省会建欢愉宫殿，安全地区建奴工营地，边境要地建折磨者城塞。**

两三座成熟欢愉宫殿可以提供稳定收入，缓解后方奴工营地逐渐衰退造成的经济压力。

## 资源怎么花

### 奴工

主要用于：

- 建设和升级欢愉宫殿。
- 使用军队的色孽恩惠，换取数回合的临时强化。
- 执行部分色孽仪式、教团或派系行动。

前期应先保证第一座欢愉宫殿能够建设和升级，再考虑频繁开启临时恩惠。

### 恶堕

恶堕主要由欢愉宫殿建筑产生，用于购买折磨者贡品，包括：

- 战前使用的一次性单位强化。
- 领主和英雄使用的独特魔法物品。
- 与欢愉宫殿建筑链关联的永久全局升级。

一般优先购买能够强化经济、招募能力或迪卡拉本人的长期升级。一次性强化留给真正困难的战斗。

### 金钱

仍然负责普通单位招募和军队维持费。由于欢愉宫殿主要消耗奴工建设，迪卡拉通常可以把更多金钱投入军队扩张。

## 战斗风格

迪卡拉属于**高速刺杀、侧后夹击、连续转场**型领主。她不是固定在前线承受伤害的坦克。

### 标准战斗循环

```text
步兵固定敌军
→ 迪卡拉与高速单位集中一侧
→ 绕后攻击远程、法师或已接战单位
→ 制造侧后冲锋与局部包围
→ 击溃目标后立即脱离
→ 转向下一支敌军，形成连续溃败
```

### 迪卡拉本人的任务

优先攻击：

1. 炮兵和远程步兵。
2. 脆弱法师与落单英雄。
3. 已经被己方步兵固定的单位侧后方。
4. 正在动摇或溃逃的高价值目标。

尽量避开：

- 长枪、长戟和其他反大型单位。
- 强力近战决斗领主。
- 多队敌军形成的包围。
- 火枪、弩手和炮兵的集中射击。

她的优势是极高速度与出色的加减速能力。正确操作是频繁接敌和脱离，而不是站在一个目标旁边持续互砍。

## 军队搭配与阵型

迪卡拉的技能可以强化掠夺者步兵、骑兵、战车和地狱行者。前中期不必急于把整支军队换成昂贵恶魔。

推荐分工：

- **中央4—6队：** 奉献掠夺者、奉献者或持鞭混沌勇士，负责暂时固定敌军。
- **两翼4—6队：** 地狱行者、探索骑兵、战车、色孽兽或其他高速单位。
- **角色：** 迪卡拉负责后排刺杀；斯提卡尔进一步放大掠夺者部队。
- **预备队1—2队：** 拦截敌方骑兵，或在突破后加入追击。

不要平均分散所有高速单位。将大部分机动力集中在一侧，先打穿一个翼，再从侧后方卷向中央。

## 与妙影的区别

两人的战斗逻辑几乎相反：

| 对比 | 妙影 | 迪卡拉 |
| --- | --- | --- |
| 军队风格 | 防守型远程阵地战 | 进攻型高速近战 |
| 主要输出 | 弩手、火枪、炮兵和法术 | 侧后冲锋、快速近战和士气打击 |
| 前排任务 | 长时间稳定抗线 | 暂时黏住敌人 |
| 领主定位 | 法师、治疗者、龙形局部肉盾 | 高速刺客与侧袭者 |
| 开战节奏 | 让炮兵逼迫敌军进攻 | 主动分割、包围和追击敌军 |
| 操作要求 | 维持宁和、阵型和射界 | 频繁移动、冲锋、撤离和更换目标 |
| 容错率 | 较高 | 较低 |

一句话记忆：**妙影不要乱动，迪卡拉不要站桩。**

## 前期执行清单

1. 尽快建立第一座欢愉宫殿并启动恶堕生产。
2. 安全小城优先转换为奴工营地。
3. 面向主要敌人的前线设置折磨者城塞。
4. 先用廉价前排填满阵线，把预算投入高速侧袭单位。
5. 保持主动进攻，避免奴工来源中断。
6. 永久贡品和全局升级优先于普通战斗中的随意消耗。
7. 手动战斗中集中打穿一翼，不要让全军正面平推。
