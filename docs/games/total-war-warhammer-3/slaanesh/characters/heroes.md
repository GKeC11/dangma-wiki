# 色孽全部英雄流派与加点

> 适用范围：原版游戏8.1，战役模式；以迪卡拉派系可用角色为主。英雄是否可招募仍取决于玩家拥有的游戏与DLC内容。

色孽英雄很多，但一支军队不需要全部塞满。最稳定的通用骨架是：

> **杜鲁齐受祝者负责补员，色孽教徒负责移动和支援，再从欢愉使或混沌术士中选择一名主法师。**

色孽尊荣英雄是额外的近战冲击手；斯提卡尔优先跟随迪卡拉或掠夺者比例最高的军队。

## 快速排名

| 英雄 | 主要价值 | 推荐度 | 每支主力建议 |
| --- | --- | --- | --- |
| **杜鲁齐受祝者** | 伤亡补员、奉献者强化、近战与次数制法术 | **S** | 1名，优先保证 |
| **色孽教徒** | 战役移动、召唤、战龛、建立教团 | **S/A** | 1名；容量不足时先给进攻主力 |
| **欢愉使（阴影）** | 大范围清兵、削弱重甲、训练部队 | **A** | 缺主法师时1名 |
| **欢愉使（色孽）** | 控制、减益、狂暴与近战支援 | **A** | 控制流军队1名 |
| **混沌术士（阴影）** | 更耐打的清兵法师、战龛支援 | **A** | 凡人重装军或缺前排时1名 |
| **混沌术士（色孽）** | 更耐打的控制法师、催眠麝香 | **A** | 需要控制与前线支援时1名 |
| **色孽尊荣英雄** | 单体决斗、侧后冲锋、猎杀步兵与角色 | **B/A** | 核心功能齐全后0—1名 |
| **斯提卡尔** | 掠夺者强化、光环支援、前排缠斗 | **S（限定一人）** | 跟随迪卡拉或掠夺者军 |

这里的推荐度评价的是“占用一个军队格子后提供多少不可替代的战役价值”，不是英雄单挑强度。

## 通用加点规则

英雄点数通常按以下顺序分配：

1. **嵌入军队的常驻效果**：补员、移动等影响整个战役节奏的能力最优先。
2. **核心职责**：主法师先完成关键法术，支援英雄先拿召唤、光环或兵种强化。
3. **坐骑与生存**：能稳定活着，英雄的全军效果才有意义。
4. **个人输出**：近战攻击、武器威力、冲锋和猎杀能力。
5. **地图行动技能**：只有准备长期离队当事务官时才提前。

不要因为技能树里有很多战斗技能，就推迟“补充军队”或“提升移动范围”。一支军队每回合多走一段路、少休整一回合，通常比英雄本人多杀几十人更重要。

## 杜鲁齐受祝者

![杜鲁齐受祝者技能树](/images/warhammer3/druchii-anointed-skill-tree.png)

### 定位

**必备补员英雄、奉献者部队支援者、带次数制法术的近战副将。**

受祝者嵌入军队后提供伤亡补员，这是近战为主的色孽最稀缺的战役能力。官方定位还包括猎杀敌方领主与英雄；其“虔信屠夫／Devoted Murderers”方向可让军中的奉献者获得狂暴，并在受祝者进入近战后强化本人。

### 推荐流派一：军队支援型

适合所有主力，尤其适合大量奉献者步兵的迪卡拉军队。

1. 优先加满底部的**补充军队**。
2. 取得强化奉献者的专属能力。
3. 选择实用的次数制法术：优先群体减益、范围伤害或关键单体强化。
4. 点坐骑与保命能力，再补近战攻击、武器威力和冲锋。
5. 后期再补对恐虐、精灵等限定敌人的技能。

### 推荐流派二：猎将型

如果军队已经不缺补员，可强化致命冲锋、近战命中、生存和反角色技能。战斗中让普通步兵先接敌，受祝者再骑恶魔坐骑切入敌方英雄或被固定的步兵侧后方。

### 坐骑选择

- **恶魔坐骑**：通用首选，机动性更符合色孽的转场与追杀节奏。
- **冷蜥**：过渡或特定属性需求；操作手感与机动通常不如恶魔坐骑。
- **步行**：需要他紧贴奉献者前排、减少被大型单位集火时使用。

### 不推荐

- 为了地图上的击伤、破墙或妨碍补员，牺牲主力军队的补员英雄。
- 把次数制法术当成完整法系；受祝者不能取代真正主法师。

## 色孽教徒

### 定位

**战役移动核心、召唤支援、战龛载体，以及军队外的定点教团事务官。**

### 军队支援流

1. 第一优先提升军队移动范围。
2. 取得召唤类能力，让召唤单位直接压住炮兵、远程或包围点。
3. 取得必要生存能力。
4. 解锁色孽战龛后，把他放在主战线后方提供范围支援。
5. 后期再补个人近战；教徒不是主要决斗者。

战龛很慢，不要跟随迪卡拉和骑兵冲到地图另一侧。它更适合跟中央步兵一起推进，保护前排并吸引火力。

### 教团事务官流

只有确定让该英雄长期离队时，才优先建立教团、降低行动成本、提高成功率和地图生存。容量紧张的前期，一般保留一名教徒随主力增加移动，另有余量再派人建立远方教团。

## 欢愉使：阴影法系

### 定位

**高机动范围清兵法师。**阴影系拥有迷魂毒瘴、衰弱术、凋零术、摆钟、欧卡姆剃刀和阴影之坑。

### 加点顺序

1. 优先阴影之坑，用来处理已经被步兵固定的密集敌军。
2. 补摆钟或迷魂毒瘴，提供低成本输出与减速。
3. 点法术被动、法术消耗降低和奥术导体。
4. 按敌人类型补凋零术或欧卡姆剃刀。
5. 法术核心完成后，再点训练部队、坐骑与个人近战。

### 坐骑

- **色孽战驹**：最稳妥，目标小、速度快、方便找施法角度。
- **追猎者战车／尊荣追猎者战车**：能显著提高冲阵输出，但微操需求高；施法时仍需避免卡在长枪和大型单位中。

## 欢愉使：色孽法系

### 定位

**控制与近战支援法师。**相比阴影系的范围清兵，色孽系更擅长让关键目标失去行动能力、强迫敌军失控或放大己方局部近战优势。

### 加点顺序

1. 鞭笞与屈服类低成本技能，用来打开前期战斗。
2. 狂舞、癫狂或魅惑类控制技能，根据当前技能说明选择对单体或密集单位更有效的一支。
3. 法术被动、减耗和奥术导体。
4. 最后补高耗范围法术。
5. 坐骑与个人战斗技能放在法术核心之后。

适合与迪卡拉、尊荣英雄和骑兵配合：先控制目标，再集中侧后冲锋。若军队已经由色孽法系领主主施法，通常无需再带同法系欢愉使。

## 混沌术士：阴影法系

### 定位

**更耐打的主法师、凡人重装军支援者。**施法优先级与阴影欢愉使相近，但本人护甲与坐骑选择更适合靠近中央战线。

### 加点顺序

1. 阴影之坑与摆钟。
2. 法术减耗、法系被动和奥术导体。
3. 嵌入军队的常驻能力。
4. 恶魔坐骑或战龛。
5. 生存和近战能力。

当军队由混沌勇士、神选者、奉献者组成，或者需要英雄在前排附近施法时，优先混沌术士；纯恶魔高速军则更适合欢愉使。

## 混沌术士：色孽法系

### 定位

**装甲控制法师与前线减益核心。**攻击附带的催眠麝香和色孽系法术都服务于局部压制。

### 加点顺序

1. 低成本控制与减益法术。
2. 法术减耗、法系被动和奥术导体。
3. 癫狂、魅惑或范围伤害法术。
4. 坐骑与生存。
5. 个人近战。

若领主已经会完整色孽法系，改带阴影法师通常能扩充能力面；只有特别需要双控制链时才重复法系。

## 色孽尊荣英雄

### 定位

**高速单体决斗者和侧后冲击手。**官方描述强调其高速度、优秀冲锋和重武器伤害，适合攻击被固定的敌人侧后方并猎杀角色。

### 推荐流派一：猎将型

1. 单体命中、武器威力和反角色能力。
2. 速度、冲锋和追击能力。
3. 物理抗性、生命与近战防御。
4. 军队训练效果。

不要让他单独正面冲完整长枪阵或大型决斗怪。标准操作是跟随迪卡拉或骑兵，从侧面集中击杀敌方领主、法师和炮兵。

### 推荐流派二：前排副坦型

当军队缺少能接住敌方领主的角色时，先点防御、抗性和持续作战，再补输出。他仍不是传统重甲坦克，应配合步兵共同承伤。

## 斯提卡尔

### 定位

**迪卡拉的最佳副将、掠夺者体系放大器和高防御缠斗英雄。**

官方“跟随领袖／Follow the Leader”技能线专门强化掠夺者；其装备与标记还能同时提高友军速度、领导力并削弱附近敌军。

### 加点顺序

1. 跟随领袖线与所有掠夺者军队加成。
2. 范围光环和独特装备能力。
3. 近战防御、抗性和持续作战。
4. 武器威力与个人输出。

优先让他加入迪卡拉，因为迪卡拉本人也能大幅强化掠夺者、地狱行者与战车。若迪卡拉已经转成纯高级恶魔军，可把斯提卡尔调给另一支廉价掠夺者军队。

## 每支军队怎么配英雄

### 迪卡拉掠夺者主力

```text
迪卡拉
+ 斯提卡尔
+ 杜鲁齐受祝者
+ 色孽教徒
+ 1名阴影法师或色孽法师
```

这是功能最完整的组合：掠夺者强化、补员、移动、召唤和范围法术全部具备。

### 凡人重装军

```text
普通领主
+ 杜鲁齐受祝者
+ 色孽教徒
+ 混沌术士（优先与领主不同法系）
+ 可选尊荣英雄
```

### 恶魔高速军

```text
恶魔或高速领主
+ 杜鲁齐受祝者
+ 色孽教徒
+ 欢愉使（阴影或色孽）
```

欢愉使骑色孽战驹或战车，跟随高速部队寻找施法角度；教徒的战龛留在中央，不要强行跟随冲锋群。

## 常见错误

- 每军同时带两名同法系施法者，争夺同一池魔法之风。
- 有受祝者却不先点补员，导致近战军队每次大战后休整数回合。
- 把唯一教徒派去远方建立教团，使主力失去移动加成。
- 让战龛追着骑兵跑，既跟不上又暴露侧翼。
- 把所有近战英雄当正面坦克，不进行侧后冲锋与集中猎杀。
- 只看个人击杀数，忽略移动、补员、训练和军队光环带来的长期收益。
